# 照片搜索 - 启动脚本说明

## 推荐使用
- 智能启动(优先续扫否则增量).bat
  - 适用：日常重启。先尝试断点续扫，不能续扫则自动触发增量扫描。

## 其它脚本
- 启动并断点续扫(重启+续扫).bat
  - 适用：上次扫描中断后，继续扫描进度。

- 启动并扫描(重启+增量).bat
  - 适用：正常重启并做增量扫描（新增/删除/移动同步）。

- 启动照片搜索(仅启动).bat
  - 适用：只启动服务，不触发扫描。

- 清理系统代理并启动(清代理+启动).bat
  - 适用：代理导致模型下载或服务异常时，清理系统代理后启动服务（不触发扫描）。

- 仅全量扫描(服务运行中触发全量).bat
  - 适用：服务已运行时，手动触发一次全量扫描。

## 备注
- 全量扫描耗时很长（7-10 天），仅在重建索引/模型切换/重大修复后使用。
- 断点续扫与增量扫描都需要扫描跑到结束，才能同步“删除/移动”的结果。
